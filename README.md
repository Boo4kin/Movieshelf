# MovieShelf

Учебное Streamlit-приложение для поиска фильмов и выдачи рекомендаций на основе их содержания.

## Как работает

Для представления фильмов используется TF-IDF, а похожесть рассчитывается через cosine similarity. Пользователь выбирает фильм и получает список наиболее близких по содержанию вариантов.

## Возможности

- поиск фильмов по названию;
- выбор фильма из каталога;
- выдача 10 похожих фильмов;
- простой интерфейс на Streamlit.

## Стек

Python · pandas · scikit-learn · TF-IDF · cosine similarity · Streamlit

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

В репозитории также находятся используемые CSV-файлы и сохранённая модель.

Проект выполнен как учебная работа по рекомендательным системам.
